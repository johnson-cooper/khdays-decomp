No server upload

The selected ROM is read through the browser File API. The site has no upload endpoint or backend.

Exact PS2 pack format

The builder recreates KHPK version 1: original NitroFS FNT, rewritten FAT, and 2 KiB-aligned game files.

What to do next

Place the result at KHDAYS/ps2data/khdays.pak next to your PS2 port files.

Use a ROM dumped from a copy you legally own. This utility does not contain or distribute Nintendo DS game data.
